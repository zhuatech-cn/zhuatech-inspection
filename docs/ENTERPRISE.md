# 企业移动巡检与隐患整改系统企业能力

## 领域覆盖

- **巡检标准**：维护检查项、方法、阈值、照片要求和判定规则
- **区域与点位**：管理园区、区域、设备、二维码和责任归属
- **巡检计划**：配置周期、路线、人员、班组、日历和漏检升级
- **任务调度**：自动生成、派发、改派、离线缓存和进度跟踪
- **移动巡检**：支持扫码、定位、拍照、读数、签名和离线提交
- **异常与隐患**：按风险等级登记问题、临时措施和责任人
- **整改管理**：管理措施、期限、证据、逾期提醒和升级
- **复核销项**：执行独立复核、退回、关闭和复发跟踪
- **巡检分析**：分析完成率、漏检率、隐患趋势和整改时效

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业移动巡检与隐患整改系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `EAM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
